# my-coze-skills

这是我在扣子里沉淀下来的个人工作规则库，用标准 Skill 结构整理，方便：

- 版本管理：每次改规则都能看到改了什么
- 跨设备使用：换电脑、换 Agent 都能直接拉下来
- 复用到其他 AI 工具：不绑死在某一个平台

---

## 目录结构

```
my-coze-skills/
├── README.md
├── .gitignore
├── wechat-writing/          公众号写作
│   └── SKILL.md
├── financial-analysis/      财报分析
│   └── SKILL.md
├── contract-review/         合同审查（法律 + 税务双维度）
│   └── SKILL.md
└── tax-accounting/          财税核算规则（建材工贸 / 劳务 / 通用）
    └── SKILL.md
```

---

## 每个 SKILL.md 都写清三件事

1. **什么时候用**（触发条件）
2. **按什么步骤做**（执行流程）
3. **什么不能做**（硬约束 / 禁忌）

这三件事缺一件，Skill 就变成一篇没用的说明书——AI 读了不知道什么时候该拿出来，也不知道边界在哪。

---

## 怎么用

### 在扣子里用

1. 打开扣子 → 技能 → 创建技能
2. 把对应文件夹里的 `SKILL.md` 内容粘进去
3. 或者直接把整个文件夹导入

### 在 GitHub 上维护

- 改规则：直接编辑对应 `SKILL.md`，提交时写清改了什么
- 加新技能：新建一个英文短横线命名的文件夹，里面放 `SKILL.md`
- 看历史：点文件右上角的 History，能看到每次改动

### 给别的 AI 工具用

`SKILL.md` 就是带 frontmatter 的 Markdown，Claude Code、Cursor、各种 Agent 框架都能直接读。

## 安全约定（重要）

**这个仓库只放规则和方法，不放任何敏感信息。**

- ❌ 不放 API Key、Token、密码
- ❌ 不放客户真实姓名、身份证号、银行账号、手机号
- ❌ 不放真实企业的完整财务数据
- ✅ 案例一律脱敏（用"某建材工贸公司"代替真实名称，数字可保留比例关系）

`.gitignore` 里已经预置了常见敏感文件名，防止手滑上传。
