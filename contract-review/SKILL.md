# 合同审查

## 一、什么时候用

命中以下任一情况，加载本技能：

- 审一份合同（采购、销售、劳务分包、服务、租赁、借款、股权）
- 判断某条款有没有效、能不能签
- 检查发票条款、税目、付款方式是否合规
- 评估分包 / 转包是否违法
- 核对附件、清单、结算依据是否齐全
- 站在甲方或乙方某一方视角做风险排查
- 合同签之前的最后一遍过筛

---

## 二、审查框架：两个维度，缺一不可

**法律维度**看的是"能不能打、打了能不能赢"。
**税务维度**看的是"钱能不能扣、票能不能抵、会不会被查"。

很多审查只做法律，签完发现发票开不出来、税目不对、进项抵不了，损失比法律风险还大。

### 先明确立场

审查前必须先问清：**我是甲方还是乙方？**
同一份合同，甲方要防的是"对方干不好、干完出事找我"，乙方要防的是"活干完了钱要不回来"。

---

## 三、法律维度检查清单

### 1. 主体资格（最容易被忽略，也最容易致命）

- 对方是公司还是个人？营业执照查了吗？
- **经营范围**是否覆盖本合同业务？
- 需要前置资质的行业，资质有没有？（建筑施工、劳务分包、特种设备、危化品、医疗器械、劳务派遣）
- 分公司签的，有没有总公司授权？
- 法定代表人签的还是授权代表签的？授权委托书有吗？

**红线：个人承接需要企业资质的业务 = 违法分包。**
后果不只是合同可能无效，还有行政处罚 + 对下游的连带责任。

### 2. 标的与范围

- 工作内容 / 货物名称 / 服务范围写得够不够具体？能不能被随意解释？
- 数量、规格、质量标准在哪？（正文还是附件？附件有没有？）
- 交付地点、交付方式、验收标准、验收期限写了吗？
- 变更怎么处理？变更要不要书面确认？变更后价款怎么调？

### 3. 价款与结算

- 总价是暂定还是固定？暂定价的调整机制写了吗？
- 计价方式（总价包干 / 单价 × 工程量 / 成本加成）明确吗？
- 付款节点、付款比例、付款条件写清了吗？
- 结算依据是什么？工程量清单、验收单、结算书——**这些附件在不在？**
- 逾期付款有没有违约金？比例合理吗？

**常见致命问题：合同里引用了《工程量清单》《工艺标准》《技术协议》，但附件一个都没有。结算时没有任何依据，等于把定价权交给了对方。**

### 4. 责任与保险

- 违约责任是否对等？只约束一方算不算显失公平？
- 赔偿上限有没有约定？没有的话可能无限责任。
- 保险条款：**同一份合同里不同文件的保额必须一致。**
  真实踩过的坑：主合同写意外伤害险 50 万/人，安全协议写 350 万/人，出事后按哪个赔会打成死结。
- 免责条款：**约定"全部工伤责任由对方承担"大概率无效。** 工伤是法定责任，不能通过合同免除，只能约定"先由甲方承担法定责任，再向乙方全额追偿"。
- 不可抗力条款有没有？定义和后果写清了吗？

### 5. 争议解决

- 诉讼还是仲裁？只能选一个，两个都写等于没写。
- 管辖法院 / 仲裁机构明确吗？（"合同签订地法院"这种表述，签订地本身可能就是争议点）
- 适用法律写了吗？

### 6. 附件完整性

把合同正文里提到的所有附件列一张清单，逐个核对是否存在：

```
□ 工程量清单 / 货物清单
□ 技术标准 / 工艺要求
□ 验收标准与验收单模板
□ 报价单 / 结算书模板
□ 安全协议
□ 授权委托书
□ 对方资质证明
□ 保险单
```

**附件缺失 = 结算依据悬空 = 必打官司。**

## 四、税务维度检查清单

### 1. 发票条款（最高频漏洞）

- 合同里有没有发票条款？（很多合同一个字都没有）
- 开什么票：增值税专用发票 / 普通发票？
- 税率或征收率写了吗？
- 开票时间点：收款前 / 收款后 / 分期？
- 开票内容（货物或服务名称）和合同标的一致吗？
- 发票不合规怎么办？有没有"乙方需换开、否则甲方有权拒付"的约定？

**红线：整份合同没有发票条款，支出无法税前扣除。**
一笔 30 万的支出没有合规发票，按 25% 企业所得税算，直接多缴 7.5 万。

### 2. 纳税人身份与抵扣

- 对方是一般纳税人还是小规模 / 自然人？
- **自然人只能代开普通发票，增值税进项无法抵扣。**
- 如果对方是小规模，能不能开专票？税率是多少？
- 抵扣不了的部分，价款里有没有做相应折让？

### 3. 税目与实际业务是否一致

这是金税四期最敏感的一条。

- 合同名称写的业务性质，和实际干的活一致吗？
- 真实踩过的坑：合同标注"加工承揽"，实际是建筑安装服务。税目适用错误，会导致：
  - 发票税率错（13% vs 9%）
  - 三流不一致（合同流、发票流、资金流对不上）
  - 触发金税四期预警
- 混合业务（既供货又安装）有没有分别计价、分别开票？

### 4. 个税与社保

- 付给个人的款项，个税由谁承担？合同里写了吗？
- 劳务报酬个税税率 20%-40%，如果不约定，实际承担方很容易扯皮。
- **工资发放路径明确吗？**
  如果是甲方直接给乙方的人员发工资、代缴社保，很容易被认定为甲方正式员工，引发社保补缴 + 个税代扣义务。
  正确做法：款项付给乙方单位，由乙方单位发放工资、代扣个税。

### 5. 三流一致

```
合同流：谁签的合同
发票流：谁开的票、开给谁
资金流：钱从谁的账户到谁的账户
```

三者必须指向同一主体。任何一环不一致，都要有合理解释和书面依据（如委托付款协议、三方协议）。

## 五、输出格式

```
## 一、审查前提
- 合同名称：
- 我方立场：甲方 / 乙方
- 合同金额：
- 业务性质：

## 二、高优先级风险（需签署前解决）
### 法律
1. 【问题】+【依据】+【后果】+【修改建议】
### 税务
1. 【问题】+【依据】+【后果】+【修改建议】

## 三、中优先级风险（建议修改）
## 四、低优先级 / 提示项

## 五、附件核对清单
| 附件名称 | 是否齐全 | 说明 |

## 六、结论
能不能签？必须先改哪几条？
```

**每个风险点必须写全四要素：问题是什么、依据是什么（法条/逻辑）、后果是什么（金额/责任）、怎么改。**

---

## 六、什么不能做（硬约束）

1. **不凭经验断言法条**。引用法条必须准确，不确定就写"依据《XX法》相关规定"并提示核实，不编条款号。
2. **不只看法律不看税务**。两个维度必须都过一遍。
3. **不模糊表述风险**。不写"存在一定风险""建议关注"，要写"违法分包，可能被行政处罚并承担连带责任"。
4. **不替客户做商业决策**。只给风险和建议，不说"这合同别签"。
5. **不遗漏附件核对**。正文提到的每一个附件都要在清单里出现。
6. **不忽略立场**。必须明确站在甲方还是乙方，不能两边都评一遍当免责。
7. **不承诺结果**。不写"改了这条就不会有风险"。
8. **不隐瞒低概率高风险项**。哪怕只有 1% 概率触发，只要后果严重（行政处罚、连带责任、刑事），也要列出来。

## 七、交付前自检

- [ ] 立场（甲方/乙方）明确了吗？
- [ ] 主体资格查了吗？有没有违法分包？
- [ ] 保险条款在不同文件里一致吗？
- [ ] 免责条款有没有效力问题？
- [ ] 所有引用的附件都在吗？
- [ ] 发票条款有吗？税率写了吗？
- [ ] 税目和实际业务一致吗？三流一致吗？
- [ ] 个税承担方约定了吗？工资发放路径清楚吗？
- [ ] 每个风险点写全"问题+依据+后果+建议"了吗？
- [ ] 有编造的法条吗？
