# 财税核算规则

## 一、什么时候用

命中以下任一情况，加载本技能：

- 算税负率、判断是否触发预警
- 安排进项发票认证节奏
- 做开票计划、反算还能开多少票
- 给客户报价，算加点率或毛利率
- 查税收分类编码
- 做存货编码匹配、采购入库单匹配
- 算固定资产折旧、判断提足折旧后怎么处理
- 判断软件 / 订阅服务该进无形资产还是预付账款
- 算地方教育费附加、判断小规模能不能免
- 用友 T3 反结账、期末处理
- 判断一般纳税人还是小规模

## 二、建材工贸核心规则

### 1. 税负率

| 指标 | 合理区间 | 预警机制 |
|---|---|---|
| 增值税税负率 | **0.8% - 1.5%** | 低于行业均值 70% 自动预警；同比/环比波动超 ±30% 触发复核 |
| 企业所得税税负率 | **1.0% - 2.0%** | 低于 0.8% 易被核查 |
| 劳务公司净利润率 | **3% - 5%** | 低于 2% 易引发税局核查；亏损可未来 5 年税前弥补 |

计算口径：增值税税负率 = 实际缴纳增值税 ÷ 不含税销售收入。

### 2. 进项认证

- **分批勾选，认证随销项走**——不要一次全认证，避免某月进项过大形成留抵
- 未当月认证的进项，进"**待认证进项税额**"科目，不直接挂应交税费
- **避免连续 3 个月零税负**，这是典型的预警触发条件

### 3. 开票计划反算

已知：目标税负率、本期销项、已有进项
求：还能开多少不含税销项

```
可开票不含税金额 = (已有进项税额 + 已开票销项税额) ÷ 目标税率 − 已开票不含税金额
```

实操：用"进销项开票计划表"，输入目标税负率，自动反算剩余可开票额度。适配 13% 主营税率场景。

### 4. 加点定价

| 情形 | 加点区间 |
|---|---|
| 标准品 | 3% - 5% |
| 非标品 | 5% - 8% |
| 大额混批 | 5% - 8% |
| 上限 | **≤ 12%**，超过触发税负预警 |

### 5. 加点率 ↔ 毛利率换算（高频易错）

```
加点率 = 毛利 ÷ 不含税进价
毛利率 = 毛利 ÷ 不含税收入
```

对照表：

| 加点率 | 毛利率 |
|---|---|
| 5% | 4.76% |
| 8% | 7.41% |
| 10% | 9.09% |
| 12% | 10.71% |

**快捷算法**：进销项税率相同时（如都是 13%），直接用含税价算，不用转不含税：

```
加点率 = (销售含税价 ÷ 进价含税价 − 1) × 100%
```

### 6. 税收分类编码（已知案例）

| 商品 | 编码 |
|---|---|
| 步进式开水器出水电磁阀 | 109011901 |
| 车辆维修（小额配件合并） | 开"修理修配" |
| 车辆维修（大额） | 需明细分开开 |
| 单独销售配件 | 开"商品" |

编码不确定时，必须查国家税务总局最新《商品和服务税收分类编码表》，不凭记忆填。

## 三、通用核算规则

### 1. 附加税费

- **地方教育费附加：2023-2027 年统一税率 2%**
- 小规模纳税人月销售额 ≤ 10 万（季度 ≤ 30 万），免征增值税及附加
- 城建税、教育费附加按纳税人所在地分档（市区 7%/3%、县城和镇 5%/3%、其他 1%/3%）

### 2. 固定资产

- 折旧年限按税法最低年限：房屋建筑物 20 年、机器设备 10 年、器具工具家具 5 年、运输工具 4 年、电子设备 3 年
- **提足折旧后无需继续计提**，账面保留原值 + 累计折旧
- 只有实际报废 / 出售 / 毁损时，才走"固定资产清理"流程
- 未提足就处置的，先补提到处置当月，再清理

### 3. 软件与订阅服务摊销

| 类型 | 科目 | 摊销方式 |
|---|---|---|
| 永久授权软件 | 无形资产 | 按 10 年直线摊销 |
| 1 年以内的 SaaS 订阅 | 预付账款 | 按月分摊 |
| 长期订阅（1 年以上） | 长期待摊费用 | 按合同期分摊 |

判断依据是**授权性质**（永久 vs 期间），不是付款金额大小。

### 4. 用友 T3 操作

**反结账**：
- 路径：账套管理员登录 → 总账 → 期末 → 结账 → 选中对应月份 → 按 **Ctrl + Shift + F6**
- **仅支持最后一个已结账月份**，不能跳月反结账
- 要改更早月份，必须先逐月反结账回来

## 四、存货编码匹配规则（硬规则）

**必须精准匹配，禁止模糊匹配。**

- 匹配维度：**产品类型 + 规格**，两个维度完全对应才可填充
- 禁止使用：相似名称匹配、模糊匹配、关键词包含匹配
- 匹配不上就留空，标注"待补录"，**绝不猜测填一个相近的**
- 匹配完成后必须输出：匹配成功条数、未匹配条数、未匹配明细清单

真实教训：某次日丰产品入库单匹配，69 条明细最终 67 条匹配成功，2 条因规格描述缺失无法确认，标注待补录——如果当时模糊匹配填了，后续成本核算全错。

## 五、纳税人身份判断

| 判断依据 | 一般纳税人 | 小规模 |
|---|---|---|
| 申报表 | 月度《增值税纳税申报表（一般纳税人适用）》 | 季度《增值税纳税申报表（小规模纳税人适用）》 |
| 发票 | 可开专票，税率 13%/9%/6% | 多为 3% / 1% 征收率 |
| 税负率量级 | 0.8% - 1.5% | 通常按征收率，不适用税负率预警 |
| 进项抵扣 | 可以抵扣 | 不能抵扣 |

**这个判断必须先做。** 判错的后果是整份财税分析的税务部分全部失准。

## 六、什么不能做（硬约束）

1. **不确定的税率、编码、扣除标准，必须查现行法条或最新编码表**，不凭记忆写。
2. **存货编码禁止模糊匹配**。宁可留空待补录，不猜。
3. **不做跨月反结账**。用友 T3 只能反最后一个已结账月。
4. **提足折旧的固定资产不再计提折旧**，不管账面还在不在。
5. **软件摊销先看授权性质**，不是看金额、不是看发票名称。
6. **税务建议一次给明确**，不前后矛盾、不反复改口。不确定就直说不确定。
7. **不承诺税局不会查**。只说明规则和风险，不保证结果。
8. **不留"大概""应该"这类模糊表述**。给不出确定结论时，说明缺什么信息。

## 七、交付前自检

- [ ] 纳税人身份确认了吗？
- [ ] 税负率算的是"实际缴纳增值税 ÷ 不含税收入"吗？
- [ ] 进项认证节奏和销项匹配吗？有没有连续 3 个月零税负？
- [ ] 加点率和毛利率没混用吧？进销项税率一致吗？
- [ ] 税收编码查过最新编码表吗？
- [ ] 地方教育费附加是 2% 吗？小规模免税额判断了吗？
- [ ] 固定资产有没有提足还在计提？
- [ ] 软件摊销按授权性质分的吗？
- [ ] 存货编码是精准匹配吗？未匹配的标注了吗？
- [ ] 有没有凭记忆写的税率或编码？
