# 公众号写作

## 一、什么时候用

命中以下任一情况，加载本技能：

- 要写一篇公众号文章
- 把当天的随笔加工成推文
- 把一条新闻素材改成短文
- 判断某个选题值不值得写、该用哪种结构
- 给已有文章起标题、改开头
- 选配图
- 决定一篇文章该发哪个平台

---

## 二、定位（一切规则的源头）

**公众号是「认知翻译器」，不是资讯站。**

- **我是谁**：同路人，不是导师。不教人做事，只分享自己想明白的事。
- **写给谁**：30-40 岁、感觉"一直在努力但差点什么"的职场人 / 家长。
- **核心价值**：把底层认知翻译成"跟我有关的事"。

判断一篇文章能不能发，先问一句：**读者看完，会不会觉得"这说的是我"？**
如果只是"哦，这事挺新鲜"，就是资讯，不是认知翻译。

### 关键区别

| 资讯写法（不要） | 认知翻译写法（要） |
|---|---|
| 某公司发布了什么 | 这件事会让你明天上班遇到什么 |
| 数据 + 背景 + 影响分析 | 一个反常识的判断 + 具体事例 + 你能做的动作 |
| 读者是旁观者 | 读者是当事人 |

## 三、两种文章结构

### A 型：情绪体（约 900 字）

适合：一条新闻引发的一个具体处境感受。

```
【一句话新闻】
  20-40 字，把事实说清就够，不铺背景、不写数据堆砌

【这事跟你的关系】
  150-250 字，落到一个具体场景：
  通勤路上、加班到十点、给孩子交学费、被拉进一个群、填一张表

【最扎心的一句】
  30-50 字，一句能让人停下来的话，独立成段

【聊聊】
  一个具体的、能一句话回答的提问
```

要点：
- 新闻只占开头 3 行，**绝不超过全文 10%**
- 中间那段必须是"我"或"你"的处境，不是行业分析
- 结尾提问要具体到能脱口而出，不能是"你怎么看"

### B 型：认知差清单体（1000-1200 字）

适合：一条新闻里藏着 2-3 个可以迁移到普通人身上的判断。

```
【一句话新闻】
  20-40 字

【3 个认知差】
  每个认知差：加粗一句话 → 独立成段 → 配新闻里的具体事例 → 落到普通人处境
  结构固定：论点 → 事例 → 跟我有什么关系

【所以该怎么做】
  2-3 条可执行动作，每条一句话说清，能当天做

【聊聊】
  一个具体的提问
```

**B 型的关键：认知差论点必须加粗，像列清单一样一条一条摆出来。**
这是整篇文章的骨架，读者扫一眼加粗部分就该明白你要说什么。

示例（已发表）：

> **市场给"未来的位置"定价，不给"过去的成绩"定价**
>
> 一家公司亏着钱被估 2 万亿，不是因为它今年赚了多少，是因为资本在赌它三年后站在哪个位置……
>
> 这对普通人的意思不是"你也要去创业"。是你每年给自己的估值方式，可能一直是错的——你算的是"我做过什么"，市场算的是"你下一步能站在哪"。

## 四、标题规则

- **具体 + 冲突前置**：把最有张力的信息放前半句
- **不贴年龄标签**：不写"35 岁""40 岁""中年人"，改用处境描述（"一直在努力但差点什么""每天加班还是没底"）
- **不用烂梗、不用惊叹号堆砌、不用"震惊""必看"**
- 长度 15-25 字，微信列表页不截断
- 好标题长这样：
  - 《亏着钱被估 2 万亿：资本的 3 个反常识，藏着普通人的翻身逻辑》
  - 《AI 开始替你花钱了：这单乐高，提醒我把"确认键"攥紧》
  - 《一个人拉起一支 AI 小队：你以为差的是能力，其实差的是组队》

---

## 五、开头规则

**前三行决定读者走不走。**

- 第一行必须是画面或场景，不是背景交代
- 不写"随着……的发展""近年来……""在当今时代"
- 不写"很多人问我""最近有个朋友"
- 好开头示例：
  > 周六下午，一个 AI 自己挑了一盒乐高，自己下单，自己付了钱。
  > 全程没问过任何人。

---

## 六、配图规则

- **风格固定**：真人实景、治愈系、暖光。不要卡通、不要 3D 渲染、不要科幻感、不要文字海报
- **内容匹配**：图要对应所在章节的具体场景（写"深夜加班"就配夜晚台灯下的桌面，不配白天的办公室）
- **数量**：A 型 1-2 张，B 型 2-3 张，分别放在开头、中段、结尾附近
- **不出现文字**：AI 生成的图经常带错别字中文标语，出现就重新生成

---

## 七、分发策略（一鱼三吃）

同一份素材，按平台特性改写：

| 平台 | 内容形态 | 为什么 |
|---|---|---|
| 公众号 | A 型情绪体 | 订阅 + 社交推荐，靠认同感转发 |
| 头条号 / 百家号 | B 型认知差清单体 | 算法流量池，靠完读率和互动追投 |
| 知乎 | 深度长文（2500 字以上） | 搜索 + 话题长尾，靠专业度吃持续流量 |

两条红线：
1. **原创保护**：公众号先发，或当天同步，别让头条抢了原创标
2. **头条系严禁导流微信**：正文不能出现公众号名、二维码、"加我微信""关注公众号"

---

## 八、什么不能做（硬约束）

1. **不编造**。没有的事实、数字、案例，一律不写。不确定就写"据公开报道"或干脆不用。
2. **不贴年龄标签**。不写"35 岁""40 岁""人到中年"。
3. **不借术语装深度**。"熵增""路径依赖""主我客我"这类词，如果不能解释清前提和适用范围，就不要用。
4. **不把个案当普世公式**。"某人这么做成功了" ≠ "你这么做也会成功"。必须写清成立条件和边界。
5. **不制造焦虑**。可以指出问题，但必须给出可执行的动作，不能只吓人。
6. **不用烂梗、不堆感叹号、不写"震惊体"**。
7. **不做资讯搬运**。新闻是证据，不是主角，占比不超过 10%。
8. **篇幅不超**。A 型不超 1000 字，B 型不超 1300 字。写超了就是在灌水。
9. **结尾不能只升华**。必须有具体动作或具体提问，否则读者没有理由留言。

## 九、交付前自检清单

写完逐条过：

- [ ] 前三行是不是画面/场景，不是背景交代？
- [ ] 新闻占比是不是低于 10%？
- [ ] 有没有出现年龄标签？
- [ ] B 型的认知差论点有没有加粗、有没有配具体事例？
- [ ] 每个论点有没有落到"跟我有什么关系"？
- [ ] 结尾有没有 2-3 条能当天做的动作？
- [ ] 结尾提问能不能一句话回答？
- [ ] 字数在范围内？
- [ ] 有没有编造的事实或数字？
- [ ] 配图是不是真人实景暖光、有没有错别字文字？
- [ ] 标题有没有冲突前置、有没有烂梗？
