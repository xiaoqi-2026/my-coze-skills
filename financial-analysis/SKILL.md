# 财报分析

## 一、什么时候用

命中以下任一情况，加载本技能：

- 拿到一套财务报表（资产负债表 / 利润表 / 现金流量表）要看懂
- 判断一家企业经营状况好不好、风险在哪
- 排查金税四期涉税风险点
- 做银行报送口径的财报调整
- 核验报表勾稽是否配平
- 评估偿债能力、周转能力、盈利质量
- 审阅第三方（小程序、代账、咨询公司）出的财报诊断报告
- 做保本点测算、周转率年化

---

## 二、两个前置确认（不做这两步，后面全是错的）

### 前置一：主体身份

**先确认：一般纳税人还是小规模纳税人？**

这一条错，后面所有税务结论全部失准。真实踩过的坑：某第三方小程序把一家一般纳税人企业判定为小规模，导致整份体检报告的税务部分全错，还漏掉了三个核心风险。

确认方式：
- 看增值税申报表（一般纳税人用月度申报表，小规模用季度申报表）
- 看发票（一般纳税人能开专票、税率 13%/9%/6%；小规模多为 3%/1% 征收率）
- 看税负率量级（一般纳税人增值税税负率通常 0.8%-1.5%）

### 前置二：报表期间

**先确认：这套报表覆盖哪几个月？**

不做这一步会出现两个典型错误：
1. 把季度数据当全年数据算，所有比率偏小 4 倍
2. 周转率、保本点直接年化错位

正确做法：
- 明确起止月份，算出实际月数
- 年化按 **实际天数折算**，不是简单 ×12/月数（跨月天数不齐时会偏差）
- 在报告开头明确写出"本报告基于 20XX 年 X 月至 X 月共 N 个月数据，比率已按实际天数年化"

**报表期间不明，就不做年化，只做结构和趋势描述。**

## 三、分析流程（按顺序走）

### 第 1 步：勾稽核验

先验数据本身对不对，再谈分析。

| 检查项 | 公式 |
|---|---|
| 资产负债表平衡 | 资产总计 = 负债合计 + 所有者权益合计 |
| 未分配利润衔接 | 期末未分配利润 = 期初 + 本期净利润 − 分配 − 提取盈余公积 |
| 现金流量表余额衔接 | 期末现金 = 期初现金 + 本期现金净增加额 |
| 利润表与资产负债联动 | 本期净利润应能在未分配利润变动中找到对应 |
| 存货与成本 | 主营业务成本 ≈ 期初存货 + 本期采购 − 期末存货（有制造环节时需考虑人工与制造费用） |

发现差异：**先列出来，标注金额，让企业确认原因，不要自行调整平账。** 常见原因有未结转成本、跨期收入、代账调整未同步。

### 第 2 步：资产负债结构

- 资产负债率（管控目标通常 80% 以内）
- 流动比率、速动比率
- 货币资金占总资产比（过低说明流动性紧）
- 有息负债规模与结构（短期 vs 长期）

### 第 3 步：往来比率（金税四期重点）

这四项是涉税风险的高发区，必须逐项算、逐项说明：

| 比率 | 公式 | 说明 |
|---|---|---|
| 应收账款 / 营业收入 | 应收账款 ÷ 营业收入 | 偏高说明回款慢或存在虚增收入 |
| 预收账款 / 营业收入 | 预收账款 ÷ 营业收入 | 偏高说明有收入未确认，或挂账调节利润 |
| 预付账款 / 存货 | 预付账款 ÷ 存货 | 偏高说明有采购未到货，或资金被占用 |
| 其他应收款 / 总资产 | 其他应收款 ÷ 总资产 | 偏高高度警惕股东占款 |

**其他应收款里如果有股东借款，必须单独点名。** 股东长期借款不还，视同分红，要按 20% 补个税。

### 第 4 步：盈利质量

- 毛利率（与行业基准比、与自己历史比）
- 净利率
- 费用率结构（销售、管理、财务各占收入比）
- 净利润与经营性现金流的匹配度（利润好看但现金流为负，是典型的质量问题）
- 非经常性损益占比（政府补助、资产处置收益撑起来的利润不算本事）

### 第 5 步：现金流

- 经营活动现金流净额（长期为负说明主业不造血）
- 经营现金流 / 净利润（低于 0.5 要解释原因）
- 投资活动现金流（扩张还是收缩）
- 筹资活动现金流（靠借钱还是靠股东投入）
- 现金及等价物净增加额（正负和来源）

### 第 6 步：风险清单

把发现的问题按优先级排序输出。

---

## 四、输出格式

```
## 一、分析前提
- 主体：XX公司，一般纳税人 / 小规模纳税人
- 期间：20XX年X月-X月，共N个月（比率已按实际天数年化）
- 数据来源：XX（资产负债表 / 利润表 / 现金流量表 / 科目余额表）

## 二、勾稽核验结果
| 检查项 | 结果 | 差异金额 | 说明 |

## 三、核心指标
| 指标 | 本期 | 上期/基准 | 判断 |

## 四、四项往来比率（涉税风险）
| 比率 | 数值 | 风险等级 | 说明 |

## 五、风险清单
### 高优先级（需立即处理）
1. 【问题】+【金额】+【为什么是风险】+【怎么处理】
### 中优先级
### 低优先级 / 待核实

## 六、结论
3-5 句话说清：整体健康度、最大风险、最该先做的一件事
```

**每个风险点必须写全四要素：问题是什么、金额多少、为什么是风险（法条或逻辑）、怎么处理。** 只写"应收账款偏高"没有价值。

---

## 五、什么不能做（硬约束）

1. **不凭经验猜数字**。所有数字必须来自报表或科目余额表，缺数据就标注"待补"，不估算。
2. **空数据不出报告**。核心报表全为空或全为 null 时，直接返回"数据不足，请提供 XX"，不生成假报告。
3. **主体身份不明不做税务结论**。一般纳税人 / 小规模没确认，税务部分留空。
4. **期间不明不做年化**。只做结构和趋势描述。
5. **不自行平账**。发现勾稽差异，列出来让企业确认，不为了"看起来配平"而调数字。
6. **不遗漏重大科目**。其他应收款、预收账款、预付账款、应付账款这四个科目必须单独看，哪怕金额小也要说明。
7. **口径必须一致**。同一份报告里，周转率的分母（收入还是成本、年化还是未年化）必须统一，不能一处年化一处不年化。
8. **不做绝对化判断**。"这家公司要倒了"这类话不说，只说"资产负债率 80.73%，接近管控红线，需关注短期偿债能力"。
9. **税务结论必须对齐现行法条**。税率、扣除标准、优惠政策，不确定就查现行规定，不凭记忆写。

## 六、行业基准参考（建材工贸）

| 指标 | 合理区间 | 预警线 |
|---|---|---|
| 增值税税负率 | 0.8%-1.5% | 低于行业均值 70% 自动预警；同比/环比波动超 ±30% 触发复核 |
| 企业所得税税负率 | 1.0%-2.0% | 低于 0.8% 易被核查 |
| 资产负债率 | 80% 以内 | 超过 80% 需说明 |
| 劳务公司净利润率 | 3%-5% | 低于 2% 易引发税局核查 |
